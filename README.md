# Holidaze Venue Booking

Holidaze Venue Booking is the project for the CA in Workflow

## Prerequisites

- **Node.js** v18 or higher
- **npm** v9 or higher
- A valid Noroff student account (`@stud.noroff.no`) for API access

## Installation

Clone the repository and install dependencies:

# Install dependencies

npm install

# Install Playwright browsers (first-time only)

npx playwright install

# Start Tailwind watcher in one terminal

npm run dev

# Serve the site in another terminal

npm start

# Run unit tests

npm test

# Run end-to-end tests

npm run e2e
